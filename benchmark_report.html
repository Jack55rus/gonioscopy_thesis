06 / How to interpret the results

Neural-network inference is often the most expensive part of segmentation. Using more models or TTA orientations can improve predictions, but usually increases response time.

This is a single-image latency benchmark, not a maximum-throughput test. Model loading is excluded from per-image timing. Loading uses a single-worker DataLoader so preprocessing time can be measured directly. The reported total includes comparison with the ground truth, which is only needed for benchmarking.

Prediction visualizations and standalone plot files are not generated. The charts are embedded directly in this report.
